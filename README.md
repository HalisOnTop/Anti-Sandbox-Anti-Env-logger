# Anti-Env Logger & Anti-Dumper Collection
**By HalisAnteo**

Scripts to block environment loggers, dumpers, and sandbox bypasses. Prevents your code from being dumped or logged.

## Info
- Blocks env loggers and malicious dumpers.
- Catches almost all dumper tools and prevents bypasses.
- Works perfectly on Xeno, Delta, Fluxus, and other low-tier executors.
- Uses pure Roblox API. No unstable exploit functions.
- Clean execution, no memory leaks.
